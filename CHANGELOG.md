# Changelog

---

## [19.1.2] - 2025-11-14

### Features

- **Minimal Mode:** Introduced a new `mode: 'minimal'` input option. Setting the component to minimal mode will **hide the footer**, including the timestamp, metadata, and the action menu (Fullscreen, Download, Delete). This allows for clean, graph-only embeddings.

### Refactor

- **Cleanup:** Simplified the component's HTML and SCSS structure by removing redundant container elements and associated styling (`.media-default-container`).
